# Atsi AI Hub — Validation V0.2

Date de validation : 31 octobre 2026
Version cible : v0.2.0

## Objectif

Transformer le socle technique V0.1 en une interface
d'administration privée permettant de déclencher des agents,
suivre leurs exécutions et consulter leur historique.

## Architecture

- Frontend : Angular 22
- Backend : NestJS 12
- Worker : Node.js / TypeScript
- File de tâches : Redis 7 / BullMQ
- Base de données : PostgreSQL 16
- Orchestration : Docker Compose
- Hébergement : NAS Synology DS725+

## Fonctionnalités disponibles

- Authentification administrateur
- Protection des endpoints privés
- Communication Angular / NestJS
- Dashboard administrateur
- Statistiques sur les 50 dernières exécutions
- Déclenchement manuel du demo-agent
- Confirmation avant lancement
- Suivi automatique des tâches
- Historique des exécutions
- Consultation détaillée d'une exécution
- Affichage des résultats et erreurs
- Calcul de la durée d'exécution

## Endpoints principaux

- GET /api/health
- POST /api/agents/demo/run
- GET /api/agents/jobs/:id
- GET /api/agents/history
- GET /api/agents/history/:id

Les endpoints d'administration nécessitent une session
administrateur valide.
