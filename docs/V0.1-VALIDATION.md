# Atsi AI Hub — Validation V0.1

Date de validation : 27 octobre 2026

## Objectif

Valider le socle technique auto-hébergé d'Atsi AI Hub
sur un NAS Synology DS725+.

## Architecture

- Frontend : Angular 22
- Backend : NestJS
- Worker : Node.js / TypeScript
- File de tâches : Redis / BullMQ
- Base de données : PostgreSQL 16
- Orchestration : Docker Compose

## Fonctionnalités disponibles

- API NestJS avec endpoint /health
- Création d'une tâche d'agent simulé
- Traitement asynchrone par BullMQ
- Worker avec concurrence limitée à 1
- Historique des exécutions dans PostgreSQL
- Consultation des exécutions via l'API
- Dashboard Angular initial compilable

## Endpoints

- GET /health
- POST /agents/demo/run
- GET /agents/jobs/:id
- GET /agents/history
- GET /agents/history/:id

Les endpoints d'agents ne disposent pas encore
d'authentification. Ils ne doivent pas être exposés
publiquement dans cet état.
