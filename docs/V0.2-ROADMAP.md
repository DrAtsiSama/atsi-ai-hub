# Atsi AI Hub — Roadmap V0.2

## Objectif

Transformer le socle technique V0.1 en une application
d'administration privée permettant de piloter les agents
et consulter leurs exécutions.

## Étapes

- [x] 1. Préparation de l'architecture et de la branche
- [x] 2. Authentification administrateur
- [x] 3. Protection des endpoints API
- [x] 4. Connexion Angular / NestJS
- [x] 5. Dashboard administrateur
- [x] 6. Déclenchement des agents
- [ ] 7. Historique et détails d'exécution
- [ ] 8. Validation et publication V0.2.0

## Architecture

### Frontend

- Angular 22
- Angular Router
- Interfaces d'administration
- Communication HTTP avec NestJS

### Backend

- NestJS 12
- Authentification administrateur
- Protection des routes privées
- Gestion des exécutions

### Infrastructure

- Docker Compose
- PostgreSQL 16
- Redis 7
- BullMQ
- Worker TypeScript

## Principes de sécurité

- Aucun accès public aux endpoints privés sans authentification
- Aucun secret dans le dépôt Git
- Aucune exposition directe de PostgreSQL ou Redis
- Validation humaine avant toute action externe sensible
- Séparation entre administration privée et vitrine publique

## Fonctionnalités hors périmètre

- Agents IA autonomes complets
- Intégrations emploi et portfolio avancées
- Exécution d'actions externes sans validation
- Gestion multi-utilisateurs avancée

Ces fonctionnalités seront développées dans les versions suivantes.
