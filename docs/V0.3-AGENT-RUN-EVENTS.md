# ATSI AI Hub V0.3 - Journalisation des executions

## Objectif

Garantir la coherence entre les transitions des executions
et leurs evenements de journalisation.

## Architecture

- PostgreSQL : persistance des evenements.
- Worker : validation et insertion des evenements.
- Transactions : atomicite entre transition et evenement.
- API : consultation des evenements (a venir).
- Angular : historique des executions (a venir).

## Persistance

Migration :

- apps/api/migrations/004_create_agent_run_events.sql

Modules :

- agent-run-event.ts
- agent-run-event-persistence.ts
- agent-run-event-transaction.ts

Types d'evenements :

- run_started
- run_completed
- run_failed
- step_started
- step_completed
- step_failed

## Garanties transactionnelles

- Transition et evenement dans une meme transaction.
- Rejet des transitions non autorisees.
- Verification de la coherence des identifiants.
- Verification du type d'evenement.
- Rollback en cas d'echec.
- Absence d'evenements orphelins.
- Destruction des connexions dont l'etat est incertain.
- Erreur specifique AgentRunCommitUncertainError.
