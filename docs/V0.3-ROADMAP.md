# Atsi AI Hub — Roadmap V0.3

## Objectif

Transformer le socle d'administration V0.2 en un système
permettant de configurer, piloter et suivre des agents
réalisant de premières tâches métier.

## Étapes

- [x] 1. Préparation de l'architecture et de la branche
- [x] 2. Définition des agents et de leurs configurations
- [ ] 3. Persistance des agents dans PostgreSQL
- [ ] 4. Interface Angular de gestion des agents
- [ ] 5. Amélioration du moteur d'exécution BullMQ
- [ ] 6. Journalisation et suivi des étapes d'exécution
- [ ] 7. Premier agent métier Emploi
- [ ] 8. Interface IA et validation humaine
- [ ] 9. Tests, sécurité et publication V0.3.0

## Principes

- Administration privée et authentifiée
- Réutilisation de l'architecture existante
- Aucun abonnement API supplémentaire obligatoire
- Agents configurables et traçables
- Validation humaine avant toute action sensible
- Aucune action externe autonome non autorisée
- Conservation des données dans PostgreSQL
- Compatibilité avec les ressources du NAS

## Périmètre initial

- Configuration des agents
- Consultation de leurs capacités
- Exécution manuelle
- Suivi des étapes et des résultats
- Premier agent dédié à l'emploi
- Architecture extensible vers le portfolio

## Hors périmètre

- Orchestration multi-agents avancée
- Envoi automatique de candidatures
- Modification automatique de services externes
- Exposition publique de l'administration
- Déploiement de modèles IA lourds sur le NAS
